# HR Analysis Dashboard

## Project Overview

The **HR Analysis Dashboard** is a business intelligence project developed using Power BI to analyze employee-related data and generate actionable HR insights.

This dashboard helps organizations monitor workforce trends, employee performance, attrition rates, departmental distribution, and overall HR metrics through interactive visualizations and reports.

---

## Objective

The objective of this project is to:

- Analyze employee data efficiently
- Monitor attrition and retention trends
- Understand workforce distribution across departments
- Evaluate employee demographics and performance
- Support HR decision-making with data-driven insights
- Build an interactive dashboard for organizational analysis

---

## Tools & Technologies Used

- Power BI
- Data Cleaning
- Data Transformation
- Exploratory Data Analysis (EDA)
- Data Visualization
- Business Intelligence Techniques

## Dataset Information

The dataset used in this project contains HR-related employee information such as:

- Employee ID
- Department
- Job Role
- Gender
- Age
- Salary
- Attrition Status
- Education
- Experience
- Performance Rating
- Marital Status

---

## Dashboard Features

### 1. Employee Overview
Provides summary statistics including:
- Total Employees
- Active Employees
- Attrition Count
- Average Salary

### 2. Attrition Analysis
Visualizes employee attrition trends across:
- Departments
- Gender
- Age Groups
- Job Roles

### 3. Department-wise Analysis
Displays employee distribution and performance across departments.

### 4. Employee Demographics
Shows workforce insights based on:
- Gender
- Education
- Marital Status
- Experience Levels

### 5. Performance Analysis
Analyzes employee ratings and performance metrics.

### 6. Interactive Filters
Allows users to filter reports dynamically for deeper insights.

---

## Key Insights

- Certain departments show higher attrition rates compared to others.
- Employee satisfaction and performance ratings impact retention.
- Workforce demographics help identify diversity trends.
- Experience and job roles influence salary distribution.
- Interactive dashboards improve HR reporting efficiency.
